# Aman & Ananya — Royal Blue Scroll Invitation

Faithful static website conversion of the supplied Royal Blue Scroll Invitation HTML.

## Quick start

Open `index.html` in a browser, or run `python3 -m http.server 8000` in this directory.

## Deploy to Vercel

1. Create a GitHub repository, e.g. `royal-blue-wedding-invitation`, under the desired account/organization.
2. Push this directory to its `main` branch (or use `git remote add origin ...` from this packaged repository).
3. Import the repository at https://vercel.com/new; framework preset: **Other**, root: `/`.
4. Publish the site.

The photos are bundled in `assets/` and do not require external image hosting.

## Content review before sharing

This reproduces the supplied HTML rather than correcting the invitation's dates or venues. It has the first event date as **6 December 2026**, the subsequent itinerary as written, and WhatsApp RSVP links embedded in the original. Review them before distributing.
